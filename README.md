# Hi, I'm Arthur 👋

I'm a software developer based in São Paulo, Brazil. I build apps for Apple platforms (iOS and macOS) with Swift, and backends with Java and Spring Boot.

I study Software Engineering at Estácio and work as a Judiciary Analyst, with a degree in Law. That background gave me analytical thinking, attention to detail and a strong sense of responsibility, and I apply them to every system I build, from the API to the app.

## What I'm working on

- **[Home Budget](https://github.com/arthurnorat/home-budget-api)**: a household budget system with a REST API in Java 21 and Spring Boot (Firestore, Google Cloud Run) and clients for [web](https://github.com/arthurnorat/home-budget-web) (Angular), [macOS](https://github.com/arthurnorat/home-budget-macos) (SwiftUI), [iOS](https://github.com/arthurnorat/home-budget-ios) and [Android](https://github.com/arthurnorat/home-budget-android).
- **[MenuBarTimer](https://github.com/arthurnorat/menu-bar-timer)**: a minimalist Pomodoro timer that lives in the macOS menu bar.

## Open source

**Google Summer of Code 2025 with VideoLAN**: I built a Parental Control feature for the VLC iOS app, protecting sensitive actions with a passcode or Face ID. [See the code](https://code.videolan.org/videolan/vlc-ios/-/merge_requests/1457).

## Stack
